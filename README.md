# 美国云服务器：$36.9/年入门到 CN2 GIA 三网直连，机房、线路、套餐怎么选一次说清

搜"美国云服务器"的人，多数不是真想买"一台在美国的机器"，而是想解决一个具体麻烦：站打开得慢，后台点一下等三秒，或者需要一个不被各种条款来回折腾的落点。

问题在于，这个搜索词本身给不出答案。美国横跨四个时区，同样写着"洛杉矶机房"的两台机器，国内访问延迟能差出一倍；同样标着 1 核 2G，流量跑完后一台直接停机，另一台限速接着跑。价格跨度也大得离谱——$36.9 一年 和 $199.9 一个月，卖的是同一个国家、同一座城市。

真正需要判断的只有三件事：机房在哪、回程走哪条线、超量之后会怎样。下面按这个顺序拆，最后落到一个具体的商家和它目前在售的美国套餐上。

## 同样写着"洛杉矶"，体验为什么能差一倍

洛杉矶能成为中文业务默认选择的美国节点，是地理位置决定的。跨太平洋海缆大多在洛杉矶、圣何塞、西雅图一带登陆，数据包出了机房就能进主干网，不用先在美国境内绕一圈。

有人算过一个理论下限：洛杉矶到上海的光纤路径大约 11000～12000 公里，光在光纤里约 200 公里/毫秒，往返的理论延迟下限在 110～120ms。加上路由转发、排队和国内城域网的接入延迟，实测落在 150～190ms 属于正常偏好的水平。如果你买到的机器平峰时段就跑到 250ms 以上，基本可以判定是绕路了，而不是"美国就这样"。

这就是第一个反直觉的地方：纽约、达拉斯、迈阿密的机器可能更便宜，配置更漂亮，但它们到国内的延迟比洛杉矶高出 70～95ms。对网页首屏来说，这个差距用户能直接感觉到。反过来，如果你的访客主要在北美或欧洲，纽约到伦敦的延迟能压到 75～90ms，这时候硬选洛杉矶反而是错的。

先确认访客在哪，再挑机房。这一步走错，后面怎么优化都补不回来。

## 挑美国云服务器，先确认这四件事

### 一、回程走哪条线，比去程测速重要

不少商家给的测速页很好看，实际用起来后台卡顿，原因通常是去程和回程路径不对称：去程走了顺畅的国际出口，回程绕道别的地方，晚高峰 RTT 直接飙升。

想看穿这一点，用路由追踪查回程。真 CN2 GIA 的回程应该稳定出现 `59.43.x.x` 段的节点；如果回程段落回 `202.97` 这类 163 骨干网地址，那就是半程优化，名字里带不带 GIA 意义不大。

### 二、流量跑完之后，是停机还是限速

这是最容易被忽略、又最影响实际使用的一条。

常见的三种处理方式：直接断网，等到下个计费周期；限速但继续跑，速度掉到几 Mbps；或者按量加钱。对建站、跑任务、做中转的场景来说，第二种明显更省心——超量的那个月不会突然全站不可用。

判断方法很简单，看套餐页写的是"超额停机"还是"超额限速不限流量"，以及限速到多少。4Mbps 和 500Mbps 都叫"不限流量"，能做的事完全不同。

### 三、平台代际，以及所谓的"持续优化期"

处理器型号值得看一眼，但别只看型号。AMD EPYC 7003 和 9005 是两代平台，同价位下新平台的单核表现通常更好。更重要的是商家自己有没有提示这代平台还在磨合——如果官方主动说明磁盘性能和 SLA 可能低于成熟平台，那就别把核心业务直接压上去，先跑一段再说。

### 四、IP 出问题能不能换

面向国内访问的业务，IP 被墙是现实风险，不是理论风险。下单前确认换 IP 的规则：多久可以免费换一次、什么情况算免费、什么情况要收费。规则写清楚的商家，比口头承诺"随时换"的靠谱。

## DMIT 的洛杉矶产品线：一个机房，三种线路

DMIT 是 2017 年前后开始运营、在美国注册的服务商，机房覆盖洛杉矶、圣何塞、香港、东京。和"美国云服务器"这个需求最相关的是洛杉矶（LAX）机房，它在同一个机房里按线路分了三条产品线，这也是选它的人最需要搞懂的部分。

**Premium（Pro）**——官方对这条线的描述是：包含 Tier 1 加全部高级传输提供商，例如 DMIT 自有骨干和中国电信 CN2 GIA。实际路由上，电信去程走 AS4809，联通去程直连 AS4837，移动去程经香港移动 AS58453，三网回程走 CN2 GIA。这是对电信用户最友好的一条线。

**Eyeball（EB）**——走 CMIN2 方向。电信在 AS9929 和 AS58807 之间做负载分配，联通主要走 AS9929，移动主要走 AS58807。它和 Pro 的价格几乎一样，但同等配置下给的月流量更大，更适合移动、联通用户，以及需要跑更多流量的场景。

**Tier 1（T1）**——纯国际 BGP 线路，没有中国方向优化。便宜、带宽大、超量后限速也最宽松，适合访客在海外、做落地节点、或者你有自己的中转方案的场景。国内直连它，不要指望。

硬件平台方面，官网目前同时提供 AS3（AMD EPYC 7003 系列）和 AN5（AMD EPYC 9005 系列）两代，全部是 KVM 虚拟化，默认 1 个 IPv4 加 1 个 IPv6 /64。两代平台的库存和价格并不总是同步，具体以你打开购物车时看到的为准。

顺带一提，之前的高防线 LAX.sPro 已经按官方公告在 2026 年 1 月 16 日终止服务，如果你在别处看到这条线的推荐，内容已经过期了。

## 按场景，具体选哪一档

**预算卡得死，或者只做国际业务。** LAX.AS3.T1.WEE，$36.90 一年，1 核 1GB、20GB SSD、1TB 月流量、4Gbps 端口。超量后限速 100Mbps 但不停机，这个价格段里算少见。它是年付套餐，没有月付选项。

**面向国内用户的中小站。** Pro.TINY 或 EB.TINY，都是 $10.90/月。两者配置基本一致，区别是 EB 给 1.5TB 流量、2Gbps 端口，Pro 给 1TB、1Gbps 但回程更硬。电信宽带为主选 Pro，移动联通为主选 EB。

**需要跑量、看视频或做下载。** 往 EB 系列走。同样 $34.90，EB.STARTER 给 5TB，比 Pro.STARTER 的 3TB 多出三分之二，超量限速也一样。

**有多个站点或多人协作。** 别停在 2GB 内存。Pro/EB 的 STARTER 还是 2GB，真正意义上内存翻倍要到 MINI（4 核 4GB，$62.90）。如果你打算装面板、跑数据库加对象缓存，2GB 会很快吃到 swap，这不是省钱，是给自己找事。

**对延迟特别敏感（游戏服、实时接口）。** 老实说，美国节点不是最优解。洛杉矶到国内 150～190ms 已经是物理距离决定的下限，这种情况下应该考虑香港或东京节点，DMIT 同样有机房，香港 Premium 的入门价在 $39.90/月这一档。

## 下单前花十分钟该做的事

**先测，再买。** DMIT 提供 Looking Glass 和测试 IP。用 ping 和 mtr 从你或你访客所在的城市测，重点看晚高峰（20:00～23:00）的表现，平峰数据没有参考价值。

**确认换 IP 规则。** 第三方资料显示的常规规则是每 15 天可免费更换一次，其他情况 5 美元一次，部分产品线有更宽松的政策。这类规则会变，以你下单时的官方说明为准。

**留意平台提示。** 官方对 AS3 平台有过明确提示：该平台仍处于持续优化阶段，可能出现磁盘性能及 SLA 低于成熟平台的情况，介意的用户建议先测试再部署重要业务。看到这句话，就别把唯一的生产环境放上去。

**付款方式。** 支持支付宝、PayPal、信用卡这类常用渠道，对国内用户省事。虚拟化是 KVM，不是 OpenVZ，能自己装内核、跑 Docker。

## 几个常被问到的问题

**美国云服务器需要备案吗？** 不需要。服务器在美国，走的是海外机房，不涉及国内备案流程，这是很多人选它的直接原因。

**国内访问延迟多少算正常？** 洛杉矶机房平峰 150～190ms 属于正常偏优。同城不同运营商可能差 30ms 以上，移动和联通用户尤其明显，所以别人的测速结果只能当参考。

**$36.9/年那种低价套餐能建站吗？** 能，但要清楚代价。1 核 1GB 跑一个轻量 WordPress 加缓存插件是够的，同时装宝塔面板和 MySQL 就会紧张。它更适合落地节点、监控、开发测试这类用途。

**虚拟机和独立服务器怎么选？** 先看你要不要独占资源。日访问量几千的站，云服务器完全够用，配置还能随时升。真到了需要独占带宽和物理隔离的阶段，再考虑独服，成本是另一个量级。

回到最开始那个问题：美国云服务器值不值，不取决于"美国"两个字，取决于你选的是哪条线路、超量后会不会停、以及出问题时能不能换。这三件事都有明确答案之后，价格表才有比较的意义。
